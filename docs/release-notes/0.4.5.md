# DeSign Mage 0.4.5

- A calmer top of the window: fewer buttons, a zoom box you can type in, and an Align drop-down instead of six buttons
- Position and size (X, Y, W, H) now sit in the bottom bar next to Fill and Stroke, leaving more room to draw
- Done and Cancel buttons on tools that stay open, like Soft Shadow, Vector Edit, Crop and Text on Path
- Outlines and hard shadows now stay exactly as made; soft shadow, glow, feather and bevel still follow your edits
- The Image, Effects and Tools buttons at the top right are gone; everything is still in the menus
- Cancel puts the design back exactly as it was before you opened the tool
