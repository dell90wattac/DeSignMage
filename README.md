# DeSign Mage

A free vector design program for Windows, made for sign work: shapes and node editing, live text and text on a path, outlines, shadows,
bevels and gradients, picture placement and photo editing, vectorizing, and export to PDF, SVG, EPS, PNG and JPEG. It also opens older
`.lyt` sign layouts.

## Download

Get the latest version from the [Releases page](https://github.com/dell90wattac/DeSignMage/releases):
- **Installer** (`DeSignMageApp-win-Setup.exe`): installs for you only, no administrator needed, and keeps itself up to date.
- **Portable zip**: unzip and run `DeSignMage.exe`; nothing to install, no automatic updates.

Windows 10 or 11, 64-bit.
